# GAN 10-Minute RERS + SLR Experiment

This project runs a separate 10-minute GAN experiment for each RERS and SLR C program, stores raw and unique test cases in CSV, executes the unique cases, collects GCOV coverage, performs deterministic source-level mutation testing, and writes `final_results.xlsx`.

## RERS input format
RERS targets in the supplied 50-program archive read binary `int` values from stdin. The experiment therefore stores each RERS testcase as integer columns in CSV and packs those integers as 32-bit little-endian values when executing the C program.

## SLR input format
SLR targets read raw bytes from stdin. Each SLR testcase is stored in CSV as hexadecimal bytes and converted back to bytes for execution. The supplied SLR seed files are used as GAN seed material.

## Run one program
```bash
source .venv/bin/activate
python3 scripts/experiment.py --type RERS --source programs/RERS/FILE.c --out results/RERS/FILE
python3 scripts/experiment.py --type SLR --source programs/SLR/FILE.c --out results/SLR/FILE
```

## Generate Excel
```bash
python3 scripts/report.py
```

## Important
The 600-second limit is the GAN phase. Compilation, execution, GCOV and mutation testing happen afterward. Mutation score is calculated from the compilable mutants generated by the configured mutation operators; it is not inferred from coverage.
